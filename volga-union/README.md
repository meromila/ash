# volga union

проект презентационной книги милы и ксюши.

- `контекст/контекст-задачи.md` — задача, договорённости, текущий статус и ограничения;
- `контекст/исходный-контекст.txt` — полный исходный материал;
- `гайд/исходники/` — гайдбук и три предоставленных файла логотипов;
- `гайд/шрифты/` — скачанные шрифты и лицензии;
- `гайд/превью/` — визуальные страницы гайдбука;
- `гайд/install-fonts.ps1` — повторная установка доступных шрифтов для текущего пользователя.
